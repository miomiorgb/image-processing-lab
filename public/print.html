完整 MATLAB 程序

% 加噪→去噪→锐化→二值边缘
% 输入 test3.jpg；结果写入 results
clc; clear; close all;
A = imread('test3.jpg');
if size(A,3)==3
    I = rgb2gray(A);
else
    I = A;
end
I = im2double(I);
rng(2401540212,'twister');

% 1. 高斯噪声：均值0，方差0.005
J = imnoise(I,'gaussian',0,0.005);

% 2. 高斯平滑：5×5，标准差1
H = fspecial('gaussian',[5 5],1);
S = imfilter(J,H,'replicate','conv');

% 3. 正中心拉普拉斯响应加回主体
L = [0 -1 0; -1 4 -1; 0 -1 0];
D = imfilter(S,L,'replicate','conv');
K = min(max(S+0.6*D,0),1);

% 4. edge已输出logical二值边缘
BW = edge(K,'sobel');

% 5. 分区显示
figure;
subplot(2,3,1); imshow(I); title('原图');
subplot(2,3,2); imshow(J); title('加噪');
subplot(2,3,3); imshow(S); title('去噪');
subplot(2,3,4); imshow(D,[]);title('高通响应');
subplot(2,3,5); imshow(K); title('锐化');
subplot(2,3,6); imshow(BW);title('二值边缘');

% 6. 显示不等于存盘
if ~exist('results','dir')
    mkdir('results');
end
imwrite(J,fullfile('results','noise.png'));
imwrite(S,fullfile('results','denoise.png'));
imwrite(K,fullfile('results','sharpen.png'));
imwrite(BW,fullfile('results','edge.png'));

主程序：自行实现四个处理阶段

% 读图和类型准备可沿用第1页
A=imread('test3.jpg');
if size(A,3)==3
    A=rgb2gray(A);
end
I=im2double(A);
rng(2401540212);
% 方差v，高斯加噪
v=0.005;
J=min(max(I+sqrt(v)*randn(size(I)),0),1);

% 自行生成7×7高斯核，不调用fspecial
[x,y]=meshgrid(-3:3,-3:3);
sigma=1.4;
H=exp(-(x.^2+y.^2)/(2*sigma^2));
H=H/sum(H(:));
S=myconv2(J,H);

% 拉普拉斯响应叠加锐化
L=[0 -1 0;-1 4 -1;0 -1 0];
D=myconv2(S,L);
K=min(max(S+0.35*D,0),1);

% 自编Sobel双方向梯度
Hx=[-1 0 1;-2 0 2;-1 0 1]/8;
Hy=Hx';
Gx=myconv2(K,Hx);
Gy=myconv2(K,Hy);
G=sqrt(Gx.^2+Gy.^2);
% 对梯度阈值，不是对K直接分割
T=0.15*max(G(:));  % 按试题调整
BW=(G>T);        % logical二值图
imshow(BW);
imwrite(BW,'edge_manual.png');

% myconv2函数写在脚本末尾，见右栏
逐步判断：J 应比 I 多颗粒；S 应比 J 平滑；K 保留主体且轮廓更明显；G 是灰度边缘强度；BW 只含 0/1。若 K 先出现大片饱和，应先降低锐化系数并查核符号。

窗口尺寸题的最短答案

H3=ones(3)/9; H5=ones(5)/25;
H7=ones(7)/49;
S3=myconv2(I,H3);
S5=myconv2(I,H5);
S7=myconv2(I,H7);

窗口大，平均参与像素多，随机噪声通常更弱，但细节也更模糊。高斯还须同时看 σ，不能只看窗口尺寸。

自编二维卷积：边界复制

function Y=myconv2(A,H)
% H长宽为奇数；A为二维double
[M,N]=size(A);
[kr,kc]=size(H);
r=(kr-1)/2; c=(kc-1)/2;
H=rot90(H,2); % 卷积翻核180°
Y=zeros(M,N);
for i=1:M
    for j=1:N
        value=0;
        for u=1:kr
            for w=1:kc
                % 越界坐标压到最近边界
                ii=min(max(i+u-r-1,1),M);
                jj=min(max(j+w-c-1,1),N);
                value=value+H(u,w)*A(ii,jj);
            end
        end
        Y(i,j)=value;
    end
end
end

为什么要翻核？

相关：核原样和邻域逐项相乘相加；卷积：核先旋转180°。均值、高斯、上述拉普拉斯核中心对称，两者结果相同；导数核可能改变符号或方向，不能普遍混同。

平滑：Σh=1 → 常量 C 滤后仍为 C。
高通：ΣL=0 → 常量 C 响应为0。
完整锐化：K=S+α(L*S)，等效核系数和为1。

若题目指定自动阈值：Otsu

把归一化梯度分为256档，统计概率 p(k)。遍历门槛 t，分成两组，计算组概率 ω₀、ω₁ 与组均值 μ₀、μ₁；最大化：

σ²B(t)=ω₀ω₁(μ₀−μ₁)²
最终 T=t/255，BW=Gnorm>T。

组概率为0时跳过，避免除0。若需要“细边”，在梯度方向比较相邻响应，只保留局部极大值，再阈值化。固定阈值示例不声称与 Sobel 内置输出逐像素相同。

审题：“自编”要求实际展示核和运算。将 edge 或 imfilter 包装后改名，仍不满足要求。若题目还限制 conv2，就用本页循环。
核归一化 → 正负响应保留 → 叠加符号匹配 → 梯度再二值化3 / 4 · 自编

频域、重建与考前排错

频域的门槛是频率，二值化的门槛是灰度或边缘响应；数值相同也不能混记。

频域去噪 → 锐化 → 边缘

% J为[0,1]含噪灰度图；镜像扩展
[M,N]=size(J);
P=[J fliplr(J);flipud(J) rot90(J,2)];
[MP,NP]=size(P);
u=(-floor(NP/2):ceil(NP/2)-1)/NP;
v=(-floor(MP/2):ceil(MP/2)-1)/MP;
[U,V]=meshgrid(u,v);
D=sqrt(U.^2+V.^2); % 周期/像素

% 本实验截止增益取1/sqrt(2)
n=2; c=sqrt(2)-1;
dL=0.10; dH=0.025;
HL=1./(1+c*(D/dL).^(2*n));
HH=D.^(2*n)./(D.^(2*n)+c*dH^(2*n));
F=fftshift(fft2(P));

% 低通去噪、高频提升、高通响应
FL=F.*HL;
FS=FL.*(1+0.8*HH);
SF=real(ifft2(ifftshift(FL)));
KF=real(ifft2(ifftshift(FS)));
EF=real(ifft2(ifftshift(FS.*HH)));
S=min(max(SF(1:M,1:N),0),1);
K=min(max(KF(1:M,1:N),0),1);
G=abs(EF(1:M,1:N));
G=G/max(max(G(:)),eps);
BW=G>0.17; % 示例阈值，按试题改
imwrite(BW,'edge_frequency.png');

这里 c=√2−1，截止增益约0.707。常见教科书的 c=1 形式在 D=D₀ 处增益为0.5。两套定义要连同系数一起记；指导书的 freqspace 坐标也不能直接套本例周期/像素值。

频谱显示与三种重建

F=fft2(I); A=abs(F); Pha=angle(F);
V=log1p(abs(fftshift(F)).^2);
imshow(V,[]); % 显示不改原F
Ia=real(ifft2(A)); % 相位全设0
Ip=real(ifft2(exp(1i*Pha))); %幅度设1

原幅度和原相位共同保留才能完整重建。ifft2(Pha) 错把角度当频谱；ifft2(V) 错把显示图当原频谱。

几何与公式速记

B=imresize(I,1.5,'nearest');
C=imresize(I,0.5,'bilinear');
R=imrotate(I,45,'bilinear','loose');
  • 最近邻：取最近源像素，快、可能有锯齿、不生新灰度级。
  • 双线性：邻近四点按距离加权，更平滑、细节可能软化。
  • 缩小时考虑抗混叠；二值标签图优先最近邻。
  • 正角逆时针；loose 扩画布，crop 可能裁边。
  • 空间矩形变宽 → 对应方向频谱主瓣变窄；旋转 → 理想频谱同角旋转。
G=√(Gₓ²+Gᵧ²)；高斯 σ=√v。
MSE=mean((S(:)−I(:)).²)
PSNR=10log₁₀(MAX²/MSE)
归一化 MAX=1；0～255范围 MAX=255。
